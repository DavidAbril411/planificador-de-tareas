Planificador de tareas

Le das tareas que dependen unas de otras. El programa decide en qué orden correrlas, cuáles pueden ir al mismo tiempo, y las ejecuta.

1. Las tareas

Cada tarea hace trabajo de CPU durante su duración. "Depende de" = tiene que esperar a esas.

NombreDuración (s)PrioridadDepende de

2. Ejecutarlas · paralelismo

Con 1 proceso se ejecutan de a una. Con más, multiprocessing reparte las tareas que no dependen entre sí en varios núcleos. Probá con 1 y después con más.

1 proceso (sin paralelismo)

3. El planificador por dentro · las demás optimizaciones

Antes de ejecutar, el programa planifica: elige el orden y calcula cuándo termina cada tarea. Con tus 4 tareas eso tarda menos de un milisegundo y no se nota nada. Para que se note, acá se usa un proyecto de prueba de 2.000 tareas que inventa el programa (T0 a T1999, cada una espera a hasta 3 anteriores), como sería la obra de un edificio. Estas son las cosas que hace para planificar, cada una con su optimización. Tocá Apagar todas → Planificar, y después Prender todas → Planificar.
