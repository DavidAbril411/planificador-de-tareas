# Planificador de tareas

Recibe tareas que dependen unas de otras, decide en qué orden correrlas, cuáles pueden ir al mismo tiempo, y las ejecuta. Proyecto de Programación Eficiente (Universidad Blas Pascal).

[![CI](https://github.com/DavidAbril411/planificador-de-tareas/actions/workflows/ci.yml/badge.svg)](https://github.com/DavidAbril411/planificador-de-tareas/actions/workflows/ci.yml)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-lock.txt
./ejecutar_parcial2.sh web       # abre http://127.0.0.1:5050
./ci/controles.sh                # los mismos controles que el CI
```

La documentación completa es un vault de Obsidian: empezar por [documentacion/Inicio.md](documentacion/Inicio.md).
