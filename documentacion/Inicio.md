# Planificador de tareas

Documentación del proyecto. Es un vault de Obsidian guardado en el repositorio: se abre con **Obsidian → Open folder as vault → `documentacion/`**, y también se lee directamente en GitHub.

El repositorio es el lugar compartido: lo puede leer cualquiera, solo los colaboradores pueden modificarlo, y cada cambio queda en el historial de Git y pasa por el CI.
